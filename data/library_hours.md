# Режим работы библиотеки

Демонстрационный учебный документ для лабораторной работы.

Учебная библиотека открыта с понедельника по пятницу с 09:00 до 18:00. В субботу библиотека работает с 10:00 до 14:00. Воскресенье — выходной день.

В праздничные дни расписание может меняться. Актуальное объявление размещается на информационном стенде библиотеки. Если расписание на конкретный праздничный день в документах не указано, необходимо уточнить его у сотрудников.
