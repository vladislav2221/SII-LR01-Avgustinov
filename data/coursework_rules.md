# Сдача учебных работ

Демонстрационный учебный документ для лабораторной работы.

Перед отправкой учебной работы проверьте, что в репозитории присутствуют исходный код, README с инструкцией запуска и необходимые файлы конфигурации. Не добавляйте в репозиторий виртуальное окружение, кэш Python или локальную базу данных.

Если преподаватель указал требуемый формат имени репозитория или тег версии, используйте именно указанный формат. После отправки проверьте, что изменения доступны в удалённом репозитории.
